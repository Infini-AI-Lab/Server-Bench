# Which kernels you may write

In the serving tasks of this suite the kernels are yours to write: no catalog
of frozen implementations is supplied, and a kernel you wrote is the only kind
that counts as your work.

What does not change when a kernel changes: the model semantics, the p90 bars,
the correctness gates, the measurement window and the clock. A kernel change is
judged by exactly the same numbers as any other change.
